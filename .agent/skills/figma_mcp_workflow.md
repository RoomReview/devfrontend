# Skill: Figma MCP Workflow

## Description
This skill defines the exact workflow an agent should follow when asked to integrate a new UI component from the Figma design using the Model Context Protocol (MCP).

## Prerequisites
- Access to the `mcp_figma-dev-mode-mcp-server` toolset.
- Knowledge of the `design_system_rules.md`.

## Execution Steps

1. **Fetch Node Data:**
   - Use `mcp_figma-dev-mode-mcp-server_get_design_context` with the provided `nodeId`.
   - Set `clientFrameworks: "react"` and `clientLanguages: "typescript,javascript,html,css"`.
   
2. **Analyze Output:**
   - Review the generated code snippet from MCP.
   - Identify hardcoded colors (e.g., `#b02020`, `#1a2b3c`, `#f3e6de`, `#deedf8`).
   - Identify typography (e.g., `font-family: Montserrat`).

3. **Refactor to Tailwind:**
   - Convert hardcoded hex colors to Tailwind tokens:
     - `#8B0202` / `#B02020` -> `primary`
     - `#1A2B3C` -> `secondary`
     - `#F3E6DE` -> `offwhite`
     - `#DEEDF8` -> `gray`
   - Apply typography wrappers from `src/components/common/Typography.tsx` instead of raw `<p>` or `<h1>` tags where applicable.

4. **Component Generation:**
   - If the node is a reusable UI element, save it in `src/components/common/`.
   - Ensure the component uses strict TypeScript interfaces for its props.

5. **Icon Integration:**
   - Replace any SVG icons generated by MCP with `lucide-react` equivalents if a perfect match exists.
   - If a custom SVG is absolutely required, place it inside `src/components/common/Icons.tsx` as a functional component.
